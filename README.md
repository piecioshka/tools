<https://piecioshka.github.io/tools/>

## Features

### Text

- ✅ Remove Text Formatting - clean pasted text and keep it in LocalStorage
- ✅ Unicode Inspector - find Cyrillic and Greek homoglyphs, en/em dashes, unusual spaces, zero-width, BOM and bidi characters, and replace them with safe ones
- ✅ Slugify - generate URL-friendly slugs with Unicode normalization and Polish character support

### Markdown

- ✅ WYSIWYG Markdown Editor - edit visually or in Markdown source with live two-way sync, saved in LocalStorage
- ✅ Markdown → BBCode - convert Markdown to BBCode for TradingView script descriptions and forums, with the optional PineCoders style

### Encoding

- ✅ Base64 Converter - encode text to Base64 and decode Base64 to text
- ✅ URL Encode/Decode - encode and decode URL components, split a URL into parts and edit its query parameters
- ✅ Binary Converter - encode text to binary and decode binary to text

### Date & time

- ✅ Timestamp Converter - convert Unix timestamps (seconds or milliseconds, detected automatically) and dates to UTC, local time, ISO 8601 and relative time
- ✅ Date Diff - calculate the number of days between two dates

### Calculators

- ✅ Proportions - calculate proportional values and display simplified ratios
- ✅ Contrast Checker - WCAG 2 contrast ratio with AA/AAA results, also for text on a tinted background (`color-mix`)
